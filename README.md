# 🛒 Sales Fusion

## 💡 Purpose
Sales Fusion helps businesses especially grocery and electronic stores improve profits and customer satisfaction through smart dashboards and discount strategies.

## 📊 Key Features
- **Inventory Dashboard**: Visualizes available stock and highlights low inventory items.
- **Discount Dashboard**: Suggests optimal discounts based on billing history, product performance, and expiry dates.
- **Expiry-Based Pricing**: Applies dynamic discounts to near-expiry items to reduce waste and refresh stock.

## 🎯 Target Audience
- Grocery Stores
- Electronic Stores
- E-commerce Platforms
- Business Managers and Analysts

## 📈 Benefits
- Boosts profit margins
- Reduces expired stock
- Enhances customer satisfaction
- Provides actionable insights for decision-makers

## 🛠 Tech Stack
- Excel / Power BI for dashboards
- Power Automate for alerts (optional)
- SharePoint or local storage for data
- Python or Power Query for logic (if applicable)
